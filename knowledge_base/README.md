# Repositorio de Conocimiento Nikon

Este directorio sirve como base de conocimientos para el Asistente IA de Mi Nikon. Los archivos aquí contenidos son procesados para mejorar la precisión de las respuestas y extraer tips para la interfaz.

## Estructura
- `/manuals/`: Manuales técnicos y de usuario.
- `/tips/`: Guías rápidas y consejos fotográficos.
- `/courses/`: Material didáctico en PDF.
